## 3. Everyday plan (how we work)

**Daily goals (numbers, not vibes)**

| Goal | Number | How |
|---|---|---|
| First reply | under 15 min, 8am–10pm | WhatsApp + missed calls first, always |
| Outbound conversations | 8 logged | Call or voice note. “Hi” on Instagram does not count |
| Enquiries logged | 100% | If it is not in the Sheet / PMS, it does not exist |
| Content | 1 real post or 5 Stories | Only if something real happened (food, cow, sixer, guest) |
| Reviews | every checkout | QR + WhatsApp link. No checkout leaves without the ask |

**Clock (same every day from day 3)**

| When | Time | Do this |
|---|---|---|
| Morning | 45 min | Unread WhatsApp, missed calls, today’s arrivals, calendar vs any live OTA |
| Midday | 90 min | 8 outbound (photographers / planners Mon–Wed; plant HR Thu; mix Fri) |
| Afternoon | 30 min | Quotes, holds, website / Facebook / GBP one fix |
| Evening | 20 min | Tomorrow arrivals message. 1 Reel or Stories if you have proof. Log the day |
| Night | 5 min | Stages updated. Next follow-up date on every open row |

**Week layout (you are sales, not only social)**

| Day | Main job | Channel work (30 min) |
|---|---|---|
| Mon | Pipeline + corporate calls (they pick up) | GBP post |
| Tue | 15 planner / photographer conversations | Instagram Reel or Story |
| Wed | Quotes, contracts, one service fix on site | Website one change |
| Thu | HR / Admin follow-up or factory-area visit | Facebook post (same Reel) |
| Fri | Walk property as a guest. Weekend upsell (bonfire, rain dance) | WhatsApp catalog check |
| Sat | FAM or viewing **or** host arrivals. 30 min content | Tag guests (ask first) |
| Sun | Review ask every checkout. Scoreboard to owners | Plan Monday’s 8 calls |

**Sunday scoreboard (send to owners every week)**

- Occupancy % weekday vs weekend
- Room revenue + event pipeline (quoted / confirmed / lost)
- Enquiries by source (Google, WhatsApp, Facebook, call, partner)
- First-reply time
- Reviews added
- Partner conversations this week (target 40)
- Cash collected vs promised

If you only post and do not hit 8 conversations, the day failed.
